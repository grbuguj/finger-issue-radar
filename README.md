# 핑거 이슈 레이더

> 한 줄 소개: 내 업무에서 금융 규제·은행·핀테크·글로벌 이슈를 모아 **본부별로 "우리에게 무슨 의미인지"** 정리해 주는 서비스
> 판단 지점: 사람이 판단할 지점은 **이 이슈가 우리 본부에 액션이 필요한지(액션 필요 / 참고 / 무관)** 이다

## 문제
금융위·금감원 발표, 법령 개정, 은행·경쟁사 소식, 해외 동향이 매일 쏟아지지만 본부마다 "우리와 관련 있는지"를 각자 찾아 읽어야 합니다. 시행일을 놓치거나 관련 본부에 늦게 전달되는 일이 생깁니다.

## 핵심 기능
- **본부 선택** — 2026.10 조직도 기준 11개 본부. 관심 키워드로 이슈 관련도를 계산해 정렬
- **오늘의 브리핑** — 이슈마다 세 줄 요약, 본부별 영향, 근거 구분(`원문 근거` / `가설`)
- **한눈에 보기** — 정부·공공·민간 섹터 보드, 이슈 ↔ 본부 관계도(d3)
- **규제·법령 레이더** — 제정·개정·입법예고·국회 계류, 시행일 D-day 타임라인
- **사람의 판정** — 액션 필요 / 참고 / 무관 → 판정 진행률, 액션 목록
- **주간 브리핑 복사** — 메일에 바로 붙는 HTML 형식
- 실시간 새 이슈 알림, 북마크, 검색, 단축키(`/` `J` `K` `Enter` `1` `2` `3` `S` `?`)

## 실행
빌드가 필요 없는 정적 페이지입니다. `index.html`을 브라우저로 열면 됩니다.

## 저장소 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 서비스 전체 (HTML·CSS·JS, d3.js) |
| `docs/PRD.md` | 제품 요구사항 문서 |
| `.claude/skills/issue-brief/SKILL.md` | 이슈 분석 규칙 Skill (요약·본부 영향·근거 구분) |
| `scripts/check.mjs` | 하네스 — 데이터가 분석 규칙을 지키는지 자동 점검 |

```bash
node scripts/check.mjs
```

## 동작 범위와 한계
- 동작: 본부 전환, 섹터 필터, 검색, 판정, 북마크, 상세 패널, 관계도 클릭·드래그·확대, 주간 브리핑 복사
- **아직 안 되는 것**
  - 실제 수집과 AI 분석은 연결하지 않았습니다. **모든 기사·수치·법령은 예시(목업)** 입니다.
  - 판정 결과는 브라우저(localStorage)에만 저장되어 본부 내 공유는 아직 안 됩니다.
- 다음 단계: 금융위·금감원 보도자료·뉴스 RSS(키 불필요), 국가법령정보센터·OpenDART·ECOS(무료 키) 연동 → 서버에서 Skill 규칙으로 AI 분석 → 캐시
