# PRD — 핑거 이슈 레이더

## 1. 한 줄
금융 규제·은행·핀테크·글로벌 이슈를 매일 모아, 본부별로 "우리에게 무슨 의미인지"와 판정까지 한 화면에서 끝낸다.

## 2. 문제
- 이슈 출처가 흩어져 있다: 금융위·금감원 보도자료, 국회, 법령정보센터, 공시, 뉴스, 해외 매체
- 같은 이슈도 본부마다 의미가 다르다: 망분리 완화는 AI사업본부에는 기회, Tech 본부에는 점검 과제
- 시행일 관리가 사람 기억에 의존한다
- 결과 공유가 메신저 링크 전달로 끝나 "누가 무엇을 해야 하는지"가 남지 않는다

## 3. 사용자
| 사용자 | 하는 일 |
|---|---|
| 본부 담당자 (기획·PM) | 아침에 우리 본부 관련 이슈 확인, 판정, 주간 브리핑 공유 |
| 본부장·팀장 | 액션 필요 목록과 시행 임박 법령만 확인 |
| 전사 (경영기획·미래전략) | 전사 공통 화면에서 중요도 상 이슈와 섹터 흐름 확인 |

## 4. 핵심 흐름
1. 본부 선택 (2026.10 조직도: FV·DX·AX·DA·Tech, 11개 본부)
2. 관심 키워드로 관련도 계산 → 브리핑 정렬
3. 이슈 카드: 세 줄 요약 · 우리 본부 영향 · 근거 구분(원문 근거 / 가설)
4. **사람의 판정**: 액션 필요 / 참고 / 무관
5. 주간 브리핑 복사 → 메일·메신저 공유

## 5. 판단 지점
- AI는 분류·요약·본부 영향 초안까지만 만든다
- **이 이슈가 우리 본부에 액션이 필요한지는 사람이 판정한다**
- 원문에 없는 추론은 반드시 「가설」로 표시해 판정자가 구분할 수 있게 한다

## 6. 화면 구성
- 상단: 검색, 수집 상태, 알림, 사용자
- 본부 선택 바 (본부별 판정 대기 수)
- 지표: 판정 대기, 기준금리, 환율, 국고채, 신규 이슈, 시행 임박 법령
- 한눈에 보기: 이슈 ↔ 본부 관계도, 정부·공공·민간 섹터 보드
- 오늘의 브리핑 (카테고리·북마크 탭)
- 규제·법령 레이더 (120일 타임라인 + 표)
- 은행·경쟁사 동향, 글로벌 핀테크
- 판정 현황, 액션 목록, 본부별 히트맵

## 7. 데이터 소스 (실서비스 단계)
| 영역 | 소스 | 키 |
|---|---|---|
| 규제 | 금융위·금감원 보도자료 | 불필요 |
| 법령 | 국가법령정보센터 Open API | 무료 |
| 공시 | OpenDART | 무료 |
| 뉴스 | 국내·해외 뉴스 RSS | 불필요 |
| 지표 | 한국은행 ECOS | 무료 |

뉴스는 저작권을 지켜 제목·출처·링크만 보여 주고, 요약은 발췌 범위에서만 만든다.

## 8. 성공 기준
- 본부 담당자가 아침 5분 안에 우리 본부 이슈 판정을 끝낸다
- 시행 30일 이내 법령을 놓치지 않는다
- 하네스(`scripts/check.mjs`)가 모든 이슈의 분석 규칙 준수를 통과한다

## 9. 범위 밖 (현재 목업)
- 실제 수집·AI 분석 연결 (모든 데이터는 예시)
- 판정 결과의 서버 저장·본부 내 공유
- 로그인·권한
